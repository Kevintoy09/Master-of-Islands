# Serveur Flask

Ce dossier contient le backend du jeu (API Flask).

- Logique métier (gestion des villes, joueurs, ressources...)
- Routes API
- Modèles et managers

## Démarrage

1. Installer les dépendances : `pip install -r requirements.txt`
2. Lancer le serveur : `python run.py`

---
Ce dossier est indépendant du code Kivy. Toute nouvelle fonctionnalité doit être développée ici.
